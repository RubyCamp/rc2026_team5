# 共通基盤とチームの実装範囲

## 共通基盤の役割

共通基盤は、各チームが同じデータ構造と開発環境から実装を始められるようにするためのRailsアプリケーションである。

環境構築、データベース、モデル、基準データ、確認画面、テスト、CIなどを共通で用意している。

## 共通基盤に含まれるもの

### 開発環境

- Dev Container
- Ruby
- Rails
- PostgreSQL
- Bootstrap
- Hotwire
- Stimulus

### データモデル

- Business
- WorkRequest
- StaffMember
- Availability
- Assignment
- Skill
- StaffSkill
- ChangeEvent

### 基準データ

`bin/rails db:seed`を実行すると、画面やテストの確認に使用する基準データが投入される。

同じseedを複数回実行しても、同じ内容を再現できるようにする。

### 確認画面

共通基盤には、勤務依頼やスタッフなどのデータを確認するための画面が含まれている。

これらは、モデルやseedが正しく動作しているかを確認する目的でも使用する。

### 品質確認

次のコマンドで、コードスタイル、脆弱性、テスト、seedなどをまとめて確認できる。

```bash
bin/ci
```

## チームの実装範囲

各チームは共通基盤を起点に、担当する業務課題の実装を追加する。

共通基盤の環境設定やデータ構造を変更する場合は、運営へ確認する。
