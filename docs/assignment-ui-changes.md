# 仮割当機能の変更内容

## 概要

勤務依頼詳細画面の仮割当について、不足時のエラー表示、割当人数の更新、仮割当解除操作を改善した。

## 仮割当の処理

1. 勤務依頼の必要スキルと勤務可能時間を満たすスタッフを取得する。
2. 必要人数に達していない間、候補スタッフを1人ずつ仮割当する。
3. 各割当後に勤務依頼をデータベースから再読み込みし、割当済み人数を再計算する。
4. 必要人数に達した場合は処理を終了する。
5. 候補者が足りない場合は、不足人数を計算して結果を表示する。

割当後に再読み込みを行うことで、古い関連データを使って同じ判定を繰り返すことを防いでいる。

## 不足時の画面表示

候補スタッフが不足した場合、Bootstrapモーダルに次の内容を表示する。

- 「仮割当が完了しました。」
- 「実行結果：エラー」
- 必要人数に対する不足人数
- 操作ボタンは「OK」のみ

仮割当で追加されたスタッフは、割当一覧と依頼条件の「割当済み人数」の両方へ反映する。

## 仮割当の解除

仮割当が付いているスタッフごとに「解除」ボタンを表示する。

解除ボタンを押すと、スタッフ名を含むBootstrapモーダルを表示し、確認後に解除する。

```text
山田 太郎さんの仮割当を解除しますか？

[キャンセル] [解除する]
```

解除処理では、対象の勤務依頼IDと割当IDを使用する。

```ruby
@work_request = WorkRequest.find(params[:work_request_id])
assignment = @work_request.assignments.find(params[:id])
```

割当IDだけでなく勤務依頼IDも確認することで、指定された勤務依頼に属する割当だけを解除できるようにしている。

解除後は、Turbo Streamで次の内容を更新する。

- 現在の割当一覧
- 割当済み人数

## 全削除ボタン

勤務依頼詳細画面には、将来実装する全削除用の「割当解除」ボタンを残している。

現在はボタン表示のみで、全員分を削除する処理は未実装である。

## 主な変更ファイル

| ファイル | 内容 |
|---|---|
| `app/controllers/work_requests_controller.rb` | 仮割当と個人解除の処理、レスポンス制御 |
| `app/views/work_requests/show.html.erb` | 仮割当・全削除ボタン、割当人数表示 |
| `app/views/work_requests/_assignments.html.erb` | 割当一覧と個人解除モーダル |
| `app/views/work_requests/draft.turbo_stream.erb` | 仮割当後の一覧・人数・結果表示の更新 |
| `app/views/work_requests/destroy_assignment.turbo_stream.erb` | 個人解除後の一覧・人数更新 |
| `config/routes.rb` | 個人解除用DELETEルート |
